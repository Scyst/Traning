บทที่ 1: แท็ก HTML ก็เหมือน "กล่องกระดาษที่ติดฉลากไว้"

กฎเหล็กข้อเดียวของ HTML: เปิดกล่องด้วย <ชื่อ> ใส่ของข้างใน แล้วต้องปิดกล่องด้วย </ชื่อ> — กดคลิกที่ส่วนประกอบด้านล่างเพื่อดูหน้าที่จริง

🔍 ผ่าตัดโค้ด 1 บรรทัด (คลิกที่แต่ละส่วนเพื่อดูความหมาย)

<p id="actual" class="value ok" > 1,104 ชิ้น </p>

📦 แท็กเปิด <p ...> (Opening Tag)

เป็นการบอกเบราว์เซอร์ว่า "เริ่มสร้างกล่องข้อความย่อหน้า (Paragraph) ตรงนี้" เพื่อเตรียมใส่ข้อมูลข้างใน

🧱 นิสัยของกล่อง 2 แบบ: Block vs Inline

<div> / <p> = กล่องแบบ Block (กินเต็มความกว้าง 1 แถวเสมอ)
<h1> หัวข้อใหญ่ = Block (ขึ้นบรรทัดใหม่ให้เอง)
<span> ชิ้น <strong> เน้นหนา <button> กดปุ่ม
จำง่ายๆ: Block = ลังใหญ่ 1 ใบวางขวางเต็มชั้น (ใบต่อไปต้องลงชั้นล่าง) · Inline = ของชิ้นเล็ก วางเรียงต่อข้างๆ กันในบรรทัดเดียวได้

⚠️ ถ้า "ลืมปิดแท็ก </div>" จะเกิดอะไรขึ้น?


          

        

      

    


    
    

      

        
บทที่ 2: กล่องซ้อนกล่อง (Nested Boxes & กล่องแม่–กล่องลูก)

        
หน้าเว็บทั้งหน้าคือการเอา กล่องเล็ก ใส่ไว้ใน กล่องใหญ่ (เหมือนกล่องใส่อะไหล่ที่วางอยู่ในลังรวม แล้วลังรวมวางอยู่ในโกดังอีกที) ลองเอาเมาส์ชี้หรือคลิกที่โค้ดหรือกล่องได้เลย!

      


      

        
        
      


      

        

          
📝 ฝั่งโค้ด HTML (สังเกตการย่อหน้า!)

          

            
<main> // กล่องใหญ่สุด (คุณย่า)

            
  <section class="cards"> // กล่องแม่รวมการ์ด

            
    <article class="card"> // กล่องลูกใบที่ 1

            
      <p class="label">ผลิตได้ (ชิ้น)</p>

            
      <p id="actual" class="value">1,104</p>

            
    </article>

            
    <article class="card"> // กล่องลูกใบที่ 2

            
      <p class="label">เป้าหมาย (ชิ้น)</p>

            
      <p id="target" class="value">1,200</p>

            
    </article>

            
  </section>

            
</main>

          

          

            👆 ชี้หรือคลิกที่โค้ด หรือคลิกที่กล่องด้านขวา เพื่อดูว่ากล่องไหนเป็น แม่ (Parent) และกล่องไหนเป็น ลูก (Child)
          

        


        

          
📦 ภาพจำลองกล่องซ้อนกล่องจริง

          

            

              <main> (ชั้นที่ 1 · กล่องใหญ่สุด)
              

                <section class="cards"> (ชั้นที่ 2 · กล่องแม่)
                

                  

                    <article class="card"> (ลูก 1)
                    

                      <p class="label"> (หลาน)
                      ผลิตได้ (ชิ้น)
                    

                    

                      <p id="actual"> (หลาน)
                      1,104
                    

                  

                  

                    <article class="card"> (ลูก 2)
                    

                      <p class="label"> (หลาน)
                      เป้าหมาย (ชิ้น)
                    

                    

                      <p id="target"> (หลาน)
                      1,200
                    

                  

                

              

            

          

          

            ทำไมต้องจำเรื่อง "แม่–ลูก"? เพราะตอนจัดหน้าด้วย CSS เช่น display: flex; เราต้องสั่งที่ กล่องแม่ (<section class="cards">) ลูกๆ ข้างใน (<article class="card">) ถึงจะเรียงข้างกัน!
          

        

      

    


    
    

      

        
บทที่ 3: กล่อง 4 ชั้น (CSS Box Model) — ป้องกันงงเรื่อง Margin vs Padding

        
ลองลากแถบเลื่อนด้านซ้าย แล้วสังเกตว่า Padding ขยายจากข้างใน (ดันขอบกล่องให้อ้วนขึ้น) ส่วน Margin เป็นระยะว่างนอกกล่อง (ผลักกล่องข้างเคียงให้ถอยออกไป)

            ทริคจำง่ายๆ ไม่สับสน:

            🟦 Content = ของข้างใน (ข้อความ/รูป)  | 
            🟩 Padding = โฟมกันกระแทกในกล่อง (ทำกล่องอ้วน)

            🟨 Border = ผนังกล่อง  | 
            🟧 Margin = ทางเดินนอกกล่อง (ผลักเพื่อนบ้านออก)
