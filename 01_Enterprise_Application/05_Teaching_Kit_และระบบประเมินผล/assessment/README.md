# ระบบเก็บผลประเมินผู้เรียน (ระยะ 1)

ใช้ Google Forms ให้ผู้เรียนทำแบบทดสอบ แล้วสรุปผลลง Google Sheets อัตโนมัติ ผู้เรียนไม่ต้องมีบัญชี Google

## สิ่งที่ได้หลังติดตั้ง

| ชีต / ฟอร์ม | ใช้ทำอะไร | ใครกรอก |
| --- | --- | --- |
| ฟอร์ม Pre-test / Post-test | ข้อสอบชุดละ 20 ข้อ วัด CLO เดียวกันข้อต่อข้อ Post-test พลิกโจทย์และซับซ้อนขึ้น ตรวจคะแนนอัตโนมัติ ผู้เรียนเห็นคะแนนและเฉลยทันที | ผู้เรียน |
| ฟอร์มแบบประเมินความพึงพอใจ | 8 ข้อ คะแนน 1–5 และความเห็น ไม่ระบุชื่อ | ผู้เรียน |
| `ผู้เรียน` | รายชื่อ เลขที่ เวลาเรียน คะแนนสอบทฤษฎี สอบปฏิบัติ และนำเสนอ/UAT | ผู้สอน |
| `สรุปรายคน` | Pre/Post คะแนนที่เพิ่มขึ้น ผลราย CLO เวลาเรียน คะแนนรวม และผ่าน/ไม่ผ่าน | ระบบ |
| `รายงานรายคน` | เลือกชื่อผู้เรียนจาก dropdown แล้วได้รายงาน 1 หน้า | ระบบ |
| `สรุปรายรุ่น` | ค่าเฉลี่ยรายรุ่น จำนวนผ่าน และความพึงพอใจเฉลี่ย | ระบบ |
| `ผลแบบทดสอบ`, `ความพึงพอใจ` | คำตอบทุกครั้ง รวมการทำซ้ำ | ระบบ |
| `ตั้งค่า` | เกณฑ์ผ่าน น้ำหนักคะแนน และลิงก์ฟอร์มทั้งหมด | ผู้สอน |

ระบบจะอัปเดตชีตสรุปทุกครั้งที่มีคนส่งฟอร์ม และอัปเดตเองได้จากเมนู **ระบบประเมิน › อัปเดตสรุปผล** หลังกรอกคะแนนในชีต `ผู้เรียน`

## ติดตั้ง (ครั้งเดียวต่อวิชา ประมาณ 5 นาที)

1. สร้าง Google Sheet ใหม่ด้วยบัญชีที่จะใช้ดูแลข้อมูลระยะยาว (แนะนำบัญชีของหน่วยงาน ไม่ใช่บัญชีส่วนตัว)
2. ไปที่ **ส่วนขยาย › Apps Script** ลบโค้ดเดิม แล้ววางเนื้อหาไฟล์ `Code.gs` ทั้งไฟล์ กดบันทึก
3. เลือกฟังก์ชัน `setup` ด้านบน แล้วกด **Run**
4. Google จะขอสิทธิ์ใช้ Forms, Sheets และ Trigger ให้กดอนุญาต (ถ้าขึ้นว่า "Google hasn't verified this app" ให้กด Advanced › Go to … เพราะเป็นสคริปต์ของเราเอง)
5. กลับไปที่ Google Sheet แล้วรีเฟรช 1 ครั้ง จะเห็นเมนู **ระบบประเมิน** และลิงก์ฟอร์มทั้งหมดอยู่ในชีต `ตั้งค่า`

ฟอร์มที่สร้างจะอยู่ใน Google Drive ของบัญชีที่กด Run

## ใช้งานในแต่ละรุ่น

1. **ก่อนเริ่ม:** กรอกชีต `ผู้เรียน` ใส่รุ่น เลขที่ และชื่อ แล้วแจกเลขที่ให้ผู้เรียน (เช่น เขียนบนป้ายชื่อ) ระบบใช้ **รุ่น + เลขที่** จับคู่ผู้เรียนกับคำตอบ
2. **วันที่ 1 เวลา 09:15:** ส่งลิงก์ Pre-test (ทำเป็น QR code บนสไลด์ได้)
3. **ระหว่างคอร์ส:** ให้ผู้เรียนลงชื่อใน `ใบลงชื่อเข้าเรียน.pdf` ทุกช่วงเช้า-บ่าย แล้วกรอกจำนวนช่วงที่มาเรียน (เต็ม 8 ช่วง) ในคอลัมน์ `เข้าเรียน (ช่วง)`
4. **วันที่ 4:** กรอกคะแนนสอบทฤษฎี สอบปฏิบัติ และนำเสนอ/UAT เป็นเปอร์เซ็นต์ แล้วส่งลิงก์ Post-test และแบบประเมิน
5. **หลังจบรุ่น:** เปิดชีต `รายงานรายคน` เลือกชื่อ แล้ว **ไฟล์ › ดาวน์โหลด › PDF** เพื่อเก็บเป็นรายงานรายคน หรือดาวน์โหลดชีต `สรุปรายคน` เป็น Excel/CSV เพื่อนำเข้าระบบกลาง

### กติกาที่ระบบใช้

- นับเฉพาะ**การทำครั้งแรก**ของแต่ละรอบ ถ้าทำซ้ำ ระบบยังเก็บไว้ในชีต `ผลแบบทดสอบ` แต่ไม่นำมาคิดคะแนน
- ถ้ามีคนส่งฟอร์มด้วยเลขที่ที่ไม่มีในชีต `ผู้เรียน` จะขึ้นในสรุปพร้อมหมายเหตุ "ไม่มีในชีตผู้เรียน" ให้ตรวจแล้วเพิ่มในรายชื่อ
- ถ้าชื่อที่กรอกในฟอร์มไม่ตรงกับรายชื่อ จะขึ้นหมายเหตุให้เห็น ใช้ตรวจกรณีผู้เรียนเลือกเลขที่ผิด
- ผลการประเมินมี 5 แบบ: `ผ่าน`, `ไม่ผ่าน (เวลาเรียนไม่ถึง)`, `ไม่ผ่าน (คะแนนไม่ถึง)`, `รอคะแนน`, `รอข้อมูลเวลาเรียน`

### เกณฑ์ในชีต `ตั้งค่า` เป็นค่าเริ่มต้น

เวลาเรียนขั้นต่ำ 80%, น้ำหนักทฤษฎี 30 / ปฏิบัติ 40 / นำเสนอ 30 และคะแนนรวมผ่าน 60% **ยังไม่ใช่เกณฑ์ของโครงการ** ต้องแก้ให้ตรงก่อนสรุปผลจริง แก้แล้วกด **อัปเดตสรุปผล**

## ข้อควรรู้

- **ข้อมูลส่วนบุคคล (PDPA):** เก็บแค่ชื่อ หน่วยงาน และคะแนน แชร์ Google Sheet เฉพาะผู้สอน และแจ้งผู้เรียนในวันแรกว่าเก็บข้อมูลไปใช้ทำอะไร
- **ข้อสอบสองชุด:** Pre-test อยู่ใน `teaching-kit/quiz.json` และ Post-test อยู่ใน `teaching-kit/quiz_post.json` สองชุดต้องมีจำนวนข้อเท่ากันและวัด CLO เดียวกันในข้อเดียวกัน (build จะตรวจให้) ผลราย CLO ก่อนและหลังเรียนจึงเทียบกันได้ Post-test ตั้งใจให้ยากขึ้นเล็กน้อย คะแนนที่เพิ่มขึ้นจึงเป็นค่าที่ค่อนข้างระมัดระวัง
- **แก้ข้อความหลังติดตั้ง:** ถ้าแก้แค่ข้อความคำถามหรือคำอธิบายเฉลย หรือข้อความแบบประเมินความพึงพอใจใน `Code.template.gs` ให้ build ใหม่ วาง `Code.gs` ทับใน Apps Script แล้วกดเมนู **ระบบประเมิน › อัปเดตข้อความในฟอร์ม** (ฟังก์ชัน `syncFormText`) คำตอบที่ส่งมาแล้วยังอยู่ครบ ระบบจะตรวจก่อนว่าตัวเลือกและคำตอบของ Pre/Post-test ยังตรงกับฟอร์ม ถ้าไม่ตรงจะไม่แก้อะไรเลย
- **เปลี่ยนตัวเลือกหรือคำตอบของ Post-test:** ใช้เมนู **ระบบประเมิน › สร้างคำถาม Post-test ใหม่** (ฟังก์ชัน `rebuildPostTest`) ลิงก์และ QR code เดิมใช้ต่อได้ แต่ทำได้เฉพาะเมื่อฟอร์ม Post-test ยังไม่มีคำตอบ ถ้าเปลี่ยนตัวเลือกหรือคำตอบของ Pre-test หรือจำนวนข้อ ต้องติดตั้งใหม่ใน Google Sheet ไฟล์ใหม่
- **สคริปต์นี้ยังไม่เคยรันบน Google จริง** ตรรกะคำนวณผ่านการทดสอบด้วย Node แล้ว แต่ก่อนใช้กับรุ่น 1 ให้ติดตั้งในไฟล์ทดลองก่อน แล้วลองส่งฟอร์มเอง 2–3 ครั้ง

## สำหรับผู้ดูแลโค้ด (เมื่อใช้ร่วมกับสคริปต์ build ภายนอกในโฟลเดอร์ `tools/`)

```bash
python tools/build_assessment.py "00_BOI_Template_และตารางฝึกอบรม/ตารางฝึกอบรม_7วิชา_19คอร์ส_2026-10-21.xlsx" App "01_Enterprise_Application/05_Teaching_Kit_และระบบประเมินผล/teaching-kit/quiz.json" "01_Enterprise_Application/05_Teaching_Kit_และระบบประเมินผล/teaching-kit/quiz_post.json" "01_Enterprise_Application/05_Teaching_Kit_และระบบประเมินผล/assessment/Code.gs"
```

```bash
node tools/assessment/test_logic.js "01_Enterprise_Application/05_Teaching_Kit_และระบบประเมินผล/assessment/Code.gs"
```

ถ้าติดตั้งใหม่แล้วลิงก์ฟอร์มเปลี่ยน ให้แก้ `form_links.json` แล้วสร้าง PDF QR code ใหม่:

```bash
python tools/make_qr_pdf.py "01_Enterprise_Application/05_Teaching_Kit_และระบบประเมินผล/assessment/form_links.json" "01_Enterprise_Application/05_Teaching_Kit_และระบบประเมินผล/assessment/QR แบบทดสอบและแบบประเมิน.pdf"
```
