# สรุปคะแนนการสอบสำหรับ Audit (วิชา Enterprise Application · APP)

โฟลเดอร์นี้เป็นจุดเดียว (Single Source of Truth) สำหรับจัดเก็บและอัปเดตคะแนนสอบของแต่ละรุ่น โดยแยกไฟล์ออกเป็น **รุ่นละ 1 ไฟล์** เพื่อรองรับการปรับเปลี่ยนหรือโอนย้ายรายชื่อผู้เรียนในแต่ละรอบได้สะดวก

## โครงสร้างคะแนนในแบบฟอร์ม Audit

| หมวดคะแนน | คะแนนเต็ม | หมายเหตุ |
| --- | --- | --- |
| Pre-Test | 20 | แบบทดสอบก่อนเรียน (เก็บสถิติพัฒนาการ ไม่รวมในคะแนนรวม 100) |
| Post-Test | 20 | แบบทดสอบหลังเรียน (นำไปรวมในคะแนนรวม 100) |
| ข้อสอบ Final (ภาคทฤษฎี) | 30 | 6 หัวข้อ หัวข้อละ 5 คะแนน (รวมอัตโนมัติที่คอลัมน์ O) |
| สอบปฏิบัติ (ภาคปฏิบัติ) | 50 | 5 เกณฑ์ เกณฑ์ละ 10 คะแนน (รวมอัตโนมัติที่คอลัมน์ U) |
| **คะแนนรวม / เกรด / ผลการประเมิน** | **100** | `Post-Test (20) + Final (30) + ปฏิบัติ (50) = 100`, เกณฑ์ผ่าน `>= 70` (คำนวณอัตโนมัติที่คอลัมน์ V–X) |

## แนวทางการใช้งานสำหรับรุ่นถัดไป

1. คัดลอก `00_แบบฟอร์มเปล่า_สรุปคะแนน_วิชา_APP_สำหรับ_Audit.xlsx` และตั้งชื่อเป็น `09_สรุปคะแนนการสอบ_วิชา_APP_รุ่นที่_09_สำหรับ_Audit.xlsx` (หรือแก้จากไฟล์รุ่นที่ 4–8 ที่มีอยู่)
2. แก้ข้อความรุ่นและวันที่อบรมในแถวที่ 2–3 แล้วกรอกรหัสพนักงาน ชื่อ-นามสกุล และบริษัทของผู้เข้าอบรมจริง
3. กรอกเฉพาะช่องคะแนนดิบ (คอลัมน์ G–N และ P–T) คอลัมน์รวม เกรด และผลประเมินจะคำนวณให้อัตโนมัติ
4. เมื่อตรวจคะแนนครบแล้ว สามารถ Export เป็น PDF ชื่อเดียวกับไฟล์ Excel (เช่น `03_สรุปคะแนนการสอบ_วิชา_APP_รุ่นที่_03_สำหรับ_Audit.pdf`) เก็บคู่กันในโฟลเดอร์นี้
