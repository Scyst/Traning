ข้อสอบทฤษฎีออนไลน์ (50 คะแนน)

วิชา: การออกแบบ พัฒนา และบูรณาการแอปพลิเคชันระดับองค์กร · กติกา Open-World (เปิดสไลด์ / ใช้ AI / ปรึกษาเพื่อนและอาจารย์ได้)

ตอบแล้ว 0 / 30 ข้อ

ผลการสอบทฤษฎีของคุณ

0 / 50 คะแนน (0%)

ข้อมูลผู้เข้าสอบ

  • ข้อสอบมี 2 ตอน รวม 50 คะแนน เวลา 60 นาที (ตอนที่ 1 ปรนัย 30 คะแนน · ตอนที่ 2 อัตนัย 20 คะแนน)
  • กติกา Open-World: อนุญาตให้เปิดสไลด์ โค้ดตัวอย่าง อินเทอร์เน็ต ใช้ AI ปรึกษาเพื่อน และถามอาจารย์ผู้สอนได้ทุกช่องทาง
  • เน้นความเข้าใจและการนำไปใช้จริง: ตอนที่ 2 ให้เขียนอธิบายด้วยภาษาของตนเองและยกตัวอย่างให้ตรงตามโจทย์

ตอนที่ 1: ข้อสอบปรนัย 30 ข้อ (30 คะแนน · ข้อละ 1 คะแนน)

ตอนที่ 2: ข้อสอบอัตนัย 2 ข้อ (20 คะแนน)

ข้อที่ 1 (10 คะแนน · วัด CLO02, CLO05)
API ของไลน์ผลิตตอบกลับเป็น JSON ดังนี้:
{"line": "A", "output": 1050, "target": 1200}

ผู้เรียนคนหนึ่งเขียนโค้ดดึงข้อมูลดังนี้ แต่หน้าเว็บไม่แสดงตัวเลข 1050:

async function loadLine() {
  const res = await fetch('/api/line/A');
  const data = res.json();
  document.querySelector('#output').textContent = data.output;
}
ข้อที่ 2 (10 คะแนน · วัด CLO06 Software Testing)
Requirement: ช่องกรอก "จำนวนชิ้นงานเสีย" รับเฉพาะจำนวนเต็มตั้งแต่ 0 ถึง 100 ถ้ากรอกค่าที่เกิน 100 ค่าติดลบ หรือค่าที่ไม่ใช่ตัวเลข ระบบต้องแสดงข้อความ "ข้อมูลไม่ถูกต้อง" และไม่บันทึกข้อมูล

จงเขียน Test Case อย่างน้อย 4 กรณี (ครอบคลุม: กรณีปกติ, ค่าขอบ 0 และ 100, ค่านอกขอบ -1 และ 101, และข้อมูลผิดรูปแบบ เช่น ตัวอักษร/ทศนิยม)

Test Case ID ข้อมูลทดสอบ (Input) ขั้นตอนการทดสอบ ผลลัพธ์ที่คาดหวัง (Expected Result)

สำหรับผู้สอน: รวมไฟล์ผลสอบ (.json) ของผู้เรียนทั้งห้องเป็นตาราง Excel (.csv)

เลือกไฟล์ผลสอบ .json ที่ผู้เรียนส่งมาทั้งหมดพร้อมกัน ระบบจะรวมคะแนนตอนที่ 1, ตอนที่ 2 และคะแนนรวม (%) ออกมาเป็นไฟล์ CSV เพื่อนำไปวางในชีต ผู้เรียน ได้ทันที
