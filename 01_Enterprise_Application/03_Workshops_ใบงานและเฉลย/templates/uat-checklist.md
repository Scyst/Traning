## วิธีใช้

- เปิด Dashboard ของผู้พัฒนาพร้อม API ที่ใช้งานอยู่ แล้วทดสอบทีละสถานการณ์ตามลำดับ
- ทำเครื่องหมาย **ผ่าน** หรือ **ไม่ผ่าน** และจดสิ่งที่พบในช่องหมายเหตุ
- ผู้ทดสอบทำหน้าที่ "ผู้ใช้งานจริง" (Operator หรือหัวหน้างาน) ไม่ใช่ผู้พัฒนา
- จบแล้วให้ผู้ทดสอบเลือกผลการตรวจรับและลงชื่อ

## สถานการณ์ทดสอบ

| ข้อ | สถานการณ์ | ผล | หมายเหตุ |
|---|---|---|---|
| 1 | เปิด Dashboard แล้วหน้าเว็บแสดงครบ และ Console (F12) ไม่มี error สีแดง | ☐ ผ่าน ☐ ไม่ผ่าน | |
| 2 | การ์ดแสดงแรงดัน กระแส และอัตราการไหลของน้ำจาก API เป็นทศนิยม 1 ตำแหน่ง | ☐ ผ่าน ☐ ไม่ผ่าน | |
| 3 | ค่าบนการ์ดเปลี่ยนเองทุก 5 วินาที และเวลา "อัปเดตล่าสุด" เปลี่ยนตาม | ☐ ผ่าน ☐ ไม่ผ่าน | |
| 4 | เมื่อแรงดันเกิน 240 V มีคำเตือนสีแดงขึ้นเอง (ใช้ API สำรองวินาทีที่ 0–9 หรือพิมพ์ 245 ในช่องทดสอบ) | ☐ ผ่าน ☐ ไม่ผ่าน | |

| 6 | กด Start แล้วสถานะเป็น RUNNING สีเขียว และข้อความแจ้งเตือนขึ้นในช่องแจ้งเตือน | ☐ ผ่าน ☐ ไม่ผ่าน | |
