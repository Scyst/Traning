CSS: Selector, Box model และ Flexbox
สไลด์ 28–35 · Workshop 1

        
    
          
  • Selector ที่ใช้บ่อย: .card (class) · #volt (id) · .card p (p ที่อยู่ใน .card)
    • 
          
  • ถ้ากฎชนกัน ตัวที่เจาะจงกว่าชนะ: style ในแท็ก > id > class > ชื่อแท็ก ถ้าเท่ากัน ตัวที่เขียนทีหลังชนะ
    • 
          
  • Box model: เนื้อหา → padding → border → margin ใส่ box-sizing: border-box แล้วความกว้างจะรวม padding กับ border ไว้ด้วย คำนวณง่ายกว่า
    • 
          
  • Flexbox: justify-content จัดตามแนวแถว (ซ้าย-ขวา) · align-items จัดตามแนวตั้งฉาก (บน-ล่าง)
    • 
        


* { box-sizing: border-box; }

.cards {
  display: flex;      /* วางการ์ดเรียงเป็นแถว */
  flex-wrap: wrap;    /* จอแคบให้ตัดลงบรรทัดใหม่ */
  gap: 16px;          /* ระยะห่างระหว่างการ์ด */
}
.card {
  flex: 1 1 240px;    /* กว้างเท่ากัน แต่ไม่แคบกว่า 240px */
  padding: 20px;
  border-radius: 8px;
}

        
กับดักใส่ display: flex ที่ตัวการ์ดแทนที่จะใส่ที่กล่องแม่ การ์ดเลยไม่เรียงข้างกัน ให้จำว่า flex ใส่ที่กล่องที่ครอบของที่ต้องการจัดเรียง

        
ผู้เรียนถาม: Flexbox กับ Grid ใช้ต่างกันยังไง
Flexbox เหมาะกับการเรียงของในแถวเดียวหรือคอลัมน์เดียว Grid เหมาะกับตารางสองมิติ เช่น Dashboard ที่มีหลายแถวหลายคอลัมน์ (grid-template-columns: repeat(2, 1fr))

'10' - 5            // 5      แปลงเป็นตัวเลข

Number('')          // 0      ← ช่องว่างกลายเป็น 0
Number('12V')       // NaN
parseFloat('12V')   // 12
'5' == 5            // true   (แปลงชนิดก่อนเทียบ)

async function loadMeter() {
  try {
    const res = await fetch(API_URL);
    if (!res.ok) throw new Error('HTTP ' + res.status);
    const data = await res.json();
    volt.textContent = data.voltage;
    statusText.textContent = 'อัปเดตล่าสุด ' + new Date().toLocaleTimeString('th-TH');
  } catch (err) {
    statusText.textContent = 'โหลดข้อมูลไม่สำเร็จ';
    console.error(err);
  }
}
loadMeter();
setInterval(loadMeter, 5000);

  • เบราว์เซอร์บล็อกการเรียก API ข้ามโดเมน เว้นแต่ Server จะตอบ header Access-Control-Allow-Origin อนุญาตไว้

  • Postman หรือ curl ไม่โดน CORS เพราะไม่ใช่เบราว์เซอร์ จึงเห็นว่า API ใช้ได้ทั้งที่หน้าเว็บเรียกไม่ได้
    • 
          
  • เปิดไฟล์ HTML ด้วยการดับเบิลคลิก (file://) บาง API จะปฏิเสธ ให้เปิดผ่าน Live Server ใน VS Code แทน

เช็กตัวเอง
10 คำถามที่ยากกว่า Pre-test
ตอบในใจแล้วกดดูเฉลย

        
1. Number('') ได้อะไร และทำไมสำคัญกับ Workshop 2
ได้ 0 ถ้าผู้เรียนลบค่าในช่องจนว่าง โปรแกรมจะคิดว่าแรงดันเป็น 0 ต้องเช็ก input.value === '' แยกก่อน

        
2. fetch ได้ status 404 จะเข้า catch ไหม
ไม่เข้า fetch ถือว่าสำเร็จเพราะได้คำตอบกลับมา ต้องเช็ก res.ok แล้ว throw เอง

        
3. GET ใช้ได้ แต่ POST JSON ไป API เดียวกันโดน CORS ได้อย่างไร
POST ที่มี Content-Type: application/json ทำให้เบราว์เซอร์ส่ง preflight OPTIONS ก่อน ถ้า Server ไม่ตอบ OPTIONS ให้ถูกต้องจะโดนบล็อก

        
4. 401 กับ 403 ต่างกันอย่างไร
401 คือยังยืนยันตัวตนไม่ได้ (ไม่มี token หรือ token ผิด) 403 คือรู้ว่าเป็นใครแต่ไม่มีสิทธิ์ทำสิ่งนั้น

        
5. const list = []; list.push(1); error ไหม
ไม่ error const ห้ามกำหนดค่าใหม่ทั้งตัวแปร (list = [2]) แต่แก้ข้างใน Array ได้

        
6. ทำไม token ใน Workshop 4 ไม่ควรอยู่ในโค้ดหน้าเว็บของระบบจริง
โค้ดหน้าเว็บส่งไปถึงเครื่องผู้ใช้ทั้งหมด ใครก็เปิด DevTools อ่านได้ ระบบจริงต้องให้ Backend เป็นคนเก็บ token และยิง Webhook

        
7. justify-content กับ align-items ต่างกันอย่างไรใน flex แบบแถว
justify-content จัดตามแนวนอน (แกนหลัก) align-items จัดตามแนวตั้ง (แกนตั้งฉาก) ถ้าเปลี่ยนเป็น flex-direction: column สองตัวนี้จะสลับแกนกัน

        
8. PUT กับ PATCH ต่างกันอย่างไร
PUT ส่งข้อมูลทั้งก้อนไปแทนที่ของเดิม PATCH ส่งเฉพาะฟิลด์ที่จะแก้

        
9. ทำไมไม่ควรใช้ innerHTML แสดงข้อความที่ผู้ใช้พิมพ์
