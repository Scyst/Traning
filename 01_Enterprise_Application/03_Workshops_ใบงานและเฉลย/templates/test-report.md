## 1. ขอบเขตการทดสอบ

- **ทดสอบ:** หน้า Dashboard การดึงข้อมูลจาก API การอัปเดตอัตโนมัติ คำเตือนแรงดัน ปุ่ม Start/Stop และการแจ้งเตือนผ่าน Webhook
- **ไม่ทดสอบ:** _ระบุส่วนที่ไม่ได้ทดสอบ เช่น การเชื่อมต่อ PLC จริง การเข้าสู่ระบบ_

---

## 2. สภาพแวดล้อมที่ใช้ทดสอบ

| รายการ | รายละเอียด |
|---|---|
| เบราว์เซอร์ | เช่น Chrome 130, Edge 130 |
| ระบบปฏิบัติการ | เช่น Windows 11 |
| API ข้อมูล (API_URL) | เช่น http://192.168.1.10:8000/api/meter (API สำรอง) หรือ data/meter.json |
| Webhook (WEBHOOK_URL) | เช่น ช่องแจ้งเตือนห้องเรียน หรือ http://192.168.1.10:8000/api/notify |
| วิธีเปิดหน้าเว็บ | Live Server ใน VS Code |
